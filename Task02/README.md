# Task02

## Назначение

В рамках задания реализован процесс ETL для переноса исходных данных из текстовых файлов в базу данных SQLite.

Для автоматической генерации SQL-скрипта используется программа на Python `make_db_init.py`.

## Требования к окружению

Для работы необходимы:

- Python 3;
- SQLite3.

Используемые версии:

- Python 3.14.4;
- SQLite 3.46.1.

## Исходные файлы

В каталог `Task02` скопированы следующие файлы из каталога `dataset`:

- `movies.csv` — информация о фильмах;
- `ratings.csv` — оценки пользователей;
- `tags.csv` — пользовательские теги;
- `users.txt` — информация о пользователях;
- `genres.txt` — список жанров;
- `occupation.txt` — список профессий.
